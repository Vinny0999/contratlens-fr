QUICK START (5 minutes)
=======================

Terminal 1:
  ollama serve

Terminal 2:
  cd backend
  source venv/bin/activate
  uvicorn app.main:app --reload

Terminal 3:
  cd frontend
  npm run dev

Then:
  1. Open http://localhost:5173
  2. Go to Upload
  3. Upload demo-documents/sample-contract-1.md
  4. Wait for success message
  5. Go to Documents
  6. Click Chat
  7. Ask: "Quel est le coût?"
  8. See answer with citation

KEY TALKING POINTS
==================

1. ANTI-HALLUCINATION
   Every answer is grounded in contract text
   System refuses to answer without evidence

2. CITATIONS
   All answers include source references
   Users can verify by checking excerpt

3. LOCAL PROCESSING
   All data stays on your machine
   No cloud uploads, complete privacy

4. OPEN SOURCE & FREE
   Uses free Ollama + open models
   No API costs, works offline

5. MULTI-LANGUAGE
   Works with contracts in French, English, etc.
   Semantic search finds relevant passages

6. STRUCTURED OUTPUT
   Not just text answers
   Extracts dates, costs, obligations automatically
