HOW TO START (5 MINUTES)
========================

Terminal 1:
  ollama serve

Terminal 2:
  cd backend && source venv/bin/activate && pip install -r requirements.txt && uvicorn app.main:app --reload

Terminal 3:
  cd frontend && npm install && npm run dev

Then:
  Open: http://localhost:5173
  Upload: demo-documents/sample-contract-1.md
  Ask: "Quel est le coût?"
  
That's it! You're running a full contract analysis system.
